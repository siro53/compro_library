強連結成分分解
(graph/scc.hpp)

  • Last update: 2026-11-01 16:38:28+09:00

このライブラリでできること

SCC<Cost> は、有向グラフを強連結成分に分解します。強連結成分とは、成分内のどの2頂点についても、互いに有向辺をたどって到達できるような極大の頂点集合です。閉路を含むグラフを「成分間には閉路のないグラフ」に整理したいときに使えます。

この実装は、元のグラフと辺を逆向きにしたグラフをそれぞれ探索する Kosaraju 法です。頂点数を $N$、辺数を $M$ とすると、時間・空間ともに $O(N+M)$ です。

使い方

頂点数から構築する場合は、すべての有向辺を追加した後に build() を呼びます。すでにある Graph を渡す場合は、コンストラクタ内で分解まで行います。

例では $0\to1$ と $1\to0$ があるため、$0,1$ は同じ成分になります。一方、$2$ から戻る道はないので $2$ は別成分です。scc[v] が成分番号を返し、成分間に辺がある場合は始点側の番号が終点側より小さくなります。

#include "template/template.cpp"
#include "graph/scc.hpp"

int main() {
    SCC<> scc(3);
    scc.add_directed_edge(0, 1);
    scc.add_directed_edge(1, 0);
    scc.add_directed_edge(1, 2);
    scc.build();
    assert(scc[0] == scc[1] && scc[1] < scc[2]);
}

API・計算量

グラフと作業領域を合わせて $O(N+M)$ の空間を使い、再帰の深さは最大 $O(N)$ です。

API 動作・返り値 時間計算量
SCC(N) 辺なしで初期化。 O(N)
SCC(g) Graph をコピーして直ちに分解。 O(N+M)
add_directed_edge(from, to) 構築前に辺を追加。 償却 O(1)
build() 分解を実行。 O(N+M)
operator[](v) 頂点 v の成分番号。 O(1)
size() 成分数。構築後のみ。 O(1)
get_contracted_graph() 各成分を縮約した DAG。重複辺は残る。 O(N+M)

利用条件と実装上の注意

構築は一度だけ行ってください。構築後の辺追加や、Graph を渡して構築した後の再度の build() はできません。size() や成分番号も構築後に参照します。

get_contracted_graph() は各成分を1頂点に縮めた DAG を返します。成分内の辺は除かれますが、成分間の多重辺はそのまま残り、重みも保存されます。深い探索では再帰スタックが $O(N)$ に達することがあります。
