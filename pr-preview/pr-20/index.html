出典コメント付きでbundleするツール

scripts/bundle.pyを使うと、oj-bundleによる各ライブラリの挿入位置に出典コメントを自動で付けられます。ネストした include も対象で、同じファイルには最初の挿入時だけ付けます。ライブラリを含まないソースには付けません。

// Source: https://github.com/siro53/compro_library

online-judge-verify-helperをインストールした環境で、oj-bundleの代わりに実行してください。-Iなどの引数はそのまま渡せます。

python3 /path/to/compro_library/scripts/bundle.py main.cpp -I /path/to/compro_library > bundled.cpp

入力ファイルと出力先は別にしてください。

AtCoder生成AI対策ルール（20261014版）への対応として利用する場合、出典コメントを付けるだけでなく、使用するコードをコンテスト開始前にWeb上で公開しておく必要があります。他のリポジトリのコードを含める場合は、その出典も別途記載してください。
