## このライブラリでできること

`BitMatrix<MAX_WIDTH>` は、成分が $0,1$ で、加算を XOR として行う体 $\mathbb F_2$ 上の行列です。スイッチを押すと状態が反転する問題や、複数の XOR 条件を満たす変数を求める問題を、連立一次方程式 $Ax=b$ として扱えます。

各行を bitset で保持するので、ある行を別の行へ足す操作をまとめて XOR できます。行数を $H$、列数を $W$、機械語の bit 数を $w$、$B=\lceil\mathrm{MAX\_WIDTH}/w\rceil$ とすると、掃き出しの時間は $O(HW+H\min(H,W)B)$ です。

## 使い方

`a[i][j]` で係数を設定し、右辺を0/1の配列として `linear_equation_F2(a,b)` に渡します。返り値は行列の rank と解の1つで、解が存在しなければ `{-1,{}}` です。

例の方程式は $x_0\mathbin{\mathrm{xor}}x_1=1$、$x_1=0$ なので、解は $(1,0)$ です。解が複数ある場合、この関数は自由変数を0にした解を返します。元の行列と右辺は値渡しなので変更されません。

```cpp
#include "template/template.cpp"
#include "math/F2.hpp"

int main() {
    BitMatrix<8> a(2, 2);
    a[0][0] = 1; a[0][1] = 1; a[1][1] = 1;
    auto [rank, x] = linear_equation_F2(a, vector<int>{1, 0});
    assert(rank == 2 && x[0] == 1 && x[1] == 0);
}
```

## API・計算量

行列の保持に $O(HB)$ の空間を使います。方程式を解く際は、コピー・右辺・解のために追加で $O(HB+H+W)$ の空間が必要です。

| API | 動作・返り値 | 時間計算量 |
| --- | --- | --- |
| `BitMatrix(), BitMatrix(H,W)` | 零行列。デフォルトは 1×1。 | O(HB) |
| `operator[](i)` | i 行目の bitset への参照。 | O(1) |
| `row_reduction(b)` | 行列と右辺 b を破壊的に掃き出し、rank を返す。 | O(HW+H min(H,W) B) |
| `row_reduction()` | 右辺を使わず行列を掃き出す。 | 同上 |
| `linear_equation_F2(A,b)` | (rank,解の1つ)。解なしは (-1,{})。A,b はコピーして処理。 | 同上 + コピー O(HB) |

## 利用条件と実装上の注意

列数は $0\le W\le\mathrm{MAX\_WIDTH}$、右辺の長さは $H$ とし、係数・右辺は0/1で表してください。`H,W` は公開されていますが、確保した行列の形と矛盾する変更はしないでください。

`row_reduction(b)` を直接呼ぶ場合は、行列と右辺の両方が書き換わります。右辺なしの版も行列は書き換えます。ヘッダー内で非修飾の `vector` を使うため、使用例のように共通テンプレートを先に include します。
